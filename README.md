Course Introduction
This repository is for CPELX230-330: Exploring Agentic Software Engineering and Responsible AI (Term 2, 2026–2027, National University — College of Engineering, Computer Engineering). In this course, we learn how AI agents work in modern software systems, how Agile workflows and Git version control support iterative development, and how to apply responsible AI habits, risk management, and human oversight when building autonomous tools.

Personal Learning Goals
- Understand how AI agents plan steps, use tools, and handle tasks compared to traditional rule-based programs.
- Build steady habits with Git version control and short Agile/Scrum work cycles while testing and improving features.
- Practice responsible AI habits like protecting user data, spotting risky or biased outputs early, and keeping human checks in place.

Reflection from Part A
In looking at the shift from traditional software to Agentic Software Engineering, the main takeaway is that giving software autonomy changes how we design, test, and manage systems. Unlike regular programs that follow fixed rules and give the same output every time, AI agents read their situation, plan steps, and pick tools on their own based on changing context. Because their behavior can vary and evolve through trial and error, short Agile cycles and Git version control help teams test early, catch edge cases, and track changes safely. At the same time, letting agents make choices or use external tools brings real risks like hallucinations, accidental changes, data privacy leaks, prompt injection, and unfair bias. That is why clear limits, risk checks, and human-in-the-loop oversight are essential so autonomous systems stay safe, fair, and accountable in real use.
